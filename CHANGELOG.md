# Changelog

Все значимые изменения в проекте **DNS Pulse** документируются в этом файле в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.5.2] - 2026-11-13

### Исправлено и улучшено
- **Адаптивная вёрстка верхней панели и фильтров (`MainWindow.xaml`):**
  - Исправлено обрезание правой кнопки `Тест раздела (N)` и чипа группы сервисов `[Свой]` на средних ширинах окна или при открытом инспекторе — заголовки вкладок и баннеры переведены на `DockPanel LastChildFill="True"` с правым блоком кнопок в приоритете и `TextWrapping="Wrap"` у пояснений.
  - Правая группа (`Сплит-туннель`, `Обход 443`, `TargetDomain`) переведена на `WrapPanel` в `*`-колонке с уменьшением ширины инспектора до `332 px`.
- **Точный подсчёт и прозрачная подпись прогресса проверки (`MainViewModel`):**
  - При запуске **Авторежима** в конкретной категории (например, `Smart-DNS (70)`) диагностика сначала проверяет кандидатов именно открытого раздела (число проверок точно совпадает с бейджем категории `70` и подключение происходит быстрее), и только при отсутствии рабочих узлов расширяется на всю базу обхода (~147 узлов).
  - Текст прогресс-бара теперь явно отображает область проверки: `Раздел «Smart-DNS»: 19 / 70` vs `Автоподбор (Smart-DNS): 19 / 70` vs `Автоподбор (вся база обхода): ...`.

## [1.5.1] - 2026-11-13

### Исправлено и улучшено
- **Автообновление GitHub (`AppUpdateService`):**
  - Добавлена точная диагностика ошибок (`HTTP 404`: приватный репозиторий/скрытый релиз, `HTTP 401/403/429`, сетевые ошибки) вместо общего «Не удалось получить информацию о релизе с GitHub».
  - Добавлена поддержка **GitHub Token** в разделе `Настройки -> Обновления` для приватных репозиториев (включая скачивание ассетов через GitHub Release Asset API с `Accept: application/octet-stream`).
  - Добавлен автоматический фолбэк с Bootstrap DNS на системный HTTP-клиент с прокси Windows, если прямой канал ограничен.

## [1.5.0] - 2026-11-13

### Добавлено и улучшено
- **Отдельный раздел «Настройки и кастомизация» (4-я вкладка бокового меню):**
  - Раздел обновлений с GitHub перенесён из `Конфиги и база` в `Настройки` с переключателем автопроверки обновлений при запуске.
  - **Надёжный автозапуск Windows (`WindowsAutostartService`):** кавычки для путей с пробелами, флаг `--autostart --minimized`, обязательная обратная верификация записи `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` и самовосстановление пути после обновления.
  - **Поведение при закрытии (`✕`):** по умолчанию программа сворачивается в системный трей без потери работы туннеля, а в настройках можно переключить на полное завершение процесса при закрытии (плюс пункт «Выход (закрыть процесс)» в меню трея).
  - **Кастомизация и параметры сети (`AppSettingsService`):** сохранение темы (Тёмная/Светлая), 5 акцентных цветов (`Emerald`, `Azure`, `Violet`, `Amber`, `Rose`), компактного режима списка серверов, выбора Bootstrap DNS (`Auto`, `1.1.1.1`, `8.8.8.8`, `9.9.9.9`), блокировки IPv6 `AAAA/HTTPS`, таймаута и количества потоков проверки.
- **Авторежим («Автоподбор и автоподключение») + тестирование всего открытого раздела:**
  - Авторежим при включении (или на старте / при сбое активного узла) сам проверяет кандидатов, выбирает самый быстрый рабочий Smart-DNS (при необходимости запускает авто-сканер `/24`) и сразу подключает/переключает туннель с поддержкой автопереключения при отказе (`failover`).
  - Убрано непонятное ограничение «топ-18» — кнопка **`Тест раздела (N)`** проверяет **все** DNS-серверы открытой категории и текущего фильтра как на главном экране, так и во вкладке «Каталог».
- **Инфраструктура Smart-DNS и паритет с Android:**
  - Добавлены 6 прямых SNI-443 прокси-узлов (`Open SNI Node NL/UK/PL/DE/Nord/Central`, `smartproxy://`) из Android-версии.
  - Реальный замер TCP-443 RTT для `smartproxy://` узлов вместо фиктивных `1 мс`.
  - Пул сканера подсетей `/24` (`AUTO`) расширен до ~1150 кандидатов (шаг `4` и 16 префиксов) с быстрым предварительным фильтром `900 мс` и 36 потоками.

## [1.4.0] - 2026-11-13

### Добавлено
- **Встроенное автообновление прямо из программы (`AppUpdateService`):**
  - Тихая проверка новых релизов на GitHub (`api.github.com` + безлимитный redirect fallback через Bootstrap DNS) при запуске и кнопка ручной проверки во вкладке `Конфиги и база`.
  - Баннер с загрузкой обновления прямо внутри интерфейса, индикатором прогресса в МБ/%, обязательной проверкой целостности `SHA-256` по `SHA256SUMS.txt` и автоматическим перезапуском (поддержка как установленной через Inno Setup версии, так и standalone single-file `DnsPulse.exe`).
- **Фирменная иконка приложения и системного трея (`Assets/app.ico`):**
  - Многоразмерная векторно-сгенерированная иконка (16..256 px) для `.exe`, панели задач, окон, установщика Inno Setup и системного трея, а также векторные SVG-пути для кнопок обновления и сброса поиска.

## [1.3.0] - 2026-11-13

### Исправлено и переработано
- **Bootstrap DNS и защита от петли `127.0.0.1` (`BootstrapDnsResolver`, `DynamicBypassRegistry`):**
  - Резолв DoH-серверов и онлайн-списков выполняется напрямую через `1.1.1.1 / 8.8.8.8 / 9.9.9.9` (UDP 53 и IP-DoH fallback), минуя системный DNS и проблемные IPv6-маршруты.
  - Встроенный список защищённых AI / Streaming / Gaming-доменов загружается сразу офлайн; сплит-туннель не пропускает нецелевой трафик через Smart-DNS и глушит утечки по `AAAA` / `HTTPS (SVCB)`.
- **4-этапный пробер и системный DNS Windows:**
  - Фолбэк-цепочка `DoH (POST -> GET) -> DoT (853) -> UDP 53 -> TCP 53`, поддержка `smartproxy://`, проверка `/welcome`, `/app`, `alkalimakersuite-pa.clients6.google.com` и детектор геоблока `available-regions` / `sorry/index`.
  - Явный баннер UAC и кнопка перезапуска от имени администратора с автоподключением (`--connect-id` / `--apply-tunnel`), а также отключение утечки IPv6 DNS на активном адаптере.
- **Онлайн-фиды, сканер `/24`, поиск и интерфейс:**
  - Актуализированы фиды (`QuickDNS default_profiles.json`, `dns.malw.link`, `ImMALWARE/dns.malw.link`), добавлена фоновая автосинхронизация при старте и 12 проверенных подсетей `/24` в режиме `AUTO`.
  - Многословный поиск по всем полям узла, живой прогресс-бар тестов, кнопка отмены, обновлённый UI с тёмной и светлой темами («Restrained Graphite»).

## [1.0.0] - 2026-11-13

### Добавлено
- **Windows 10/11 Desktop (.NET 8 WPF MVVM):**
  - Локальный DNS-туннель `127.0.0.1:53` с кэшированием, счётчиком запросов, ротацией серверов и системным треем.
  - Автоматический бэкап и восстановление исходных DNS сетевых адаптеров (`restore_network_state.json`) и поддержка Windows NRPT split-routing.
  - Вкладки `Тестер`, `Каталог` и `Конфиги`, фильтры, сортировка, переключение светлой/тёмной темы «Restrained Graphite», диалог `Подбор` (`/24` сканер и синхронизация онлайн-фидов).
  - Встроенный в сборку ресурс `dns_catalog_1000.tsv` для корректной работы single-file `.exe`.
  - Скрипт установщика Windows x64 (`windows-wpf/installer/DnsPulse.iss`).
- **4-этапный движок диагностики (без ложных срабатываний):**
  - Проверка bogon/loopback IP, Anti-Direct-IP фильтр прямых CDN/Google/OpenAI подсетей, проверка companion API-доменов и реальный TLS SNI + HTTP `GET /` на порту `443` с детектом `/docs/available-regions`.
- **База 1050+ DNS-серверов (Zero-Token / Zero-Default-Favorites):**
  - Кластер Bezmezhau (`dns.bezmezhau.com`, `gemini1..20.bezmezhau.com`), MagicDNS, GeoHide (DoH + 8 узлов SNI 443), Malw.link, Comss.one, Xbox-DNS, AstraCat, Zapret.moe, Shecan, 403.online, Begzar, Electro, Radar Game, Control D, Cloudflare, Google, Quad9, OpenDNS, AdGuard, Mullvad, NextDNS, DNS.SB, DNS4EU, LibreDNS, UncensoredDNS, Yandex, GCore, Common Network/Comodo, Verisign, Level3 + 1020 каталожных серверов.
- **Веб-студия диагностики и CI/CD:**
  - Полный стек Express + `node:sqlite` + React + Vite + Tailwind CSS v4.
  - Экспорт готового open-source пакета `/api/export/windows-wpf.zip`.
  - GitHub Actions CI (`ci.yml`) и Release (`release.yml`) с генерацией `SHA256SUMS.txt`.

### Исправлено
- Очистка входящих EDNS0 `OPT`-записей (`ARCOUNT = 0`) в локальном UDP DNS-туннеле (TypeScript и C#), устраняющая некорректные ответы при запросах `nslookup` и `dnscache`.
- Использование `GET /` вместо `HEAD /` при 4-этапной TLS/SNI-проверке на порту `443`, чтобы избежать ложных отказов `403/405` от прокси.
- Безопасный разбор некорректных DoH URL в plain-text импортёре без исключений.
- Корректная группировка скобок при определении JSON-источников в модуле Discovery.
